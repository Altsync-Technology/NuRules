# 工作指南常见问题 (Q&A)

## 工作相关

**Q: 我对任务分配有疑问，怎么办？**
A: 直接在群里提问，联系相关负责人。及时处理问题，有助于避免后续的延误。

**Q: 我有事临时无法完成任务，怎么办？**
A: 参考工作指南 -> 要求与操作细则部分，记录任务上下文并在群里说明。

**Q: 我如果遇到了技术问题，该怎么解决？**
A: 请先尝试独立解决。查阅文档、搜索资料、询问 AI。如果仍无法解决，在群里描述详细的情况和尝试过的解决方法。如果问题很严重，请在仓库新建一个 issue 专门记录此问题。

## 沟通与协作

**Q: 我被批评了，怎么办？**
A: 忠言逆耳利于行。有些人就是喜欢直来直去 (例如编者)，有时可能确实参杂了情绪输出，但是你要记住，负责人从来不会针对个人。如果收到批评，保持开放的态度，积极沟通与改正，这是学习和成长的过程。如果你对此敏感，也许可以学习编者运用一下自嘲。

**Q: 我觉得我自己的建议或贡献没有被重视，怎么办？**
A: 有时可能是因为负责人过忙，或者单纯的懈怠，导致你会出现这样的错觉。请主动与负责人沟通，表达你的感受。也请谅解，人非圣贤，负责人也是会犯错的。

**Q: 团队对实习生的期望是什么？**
A: 团队希望实习生主动学习，积极汇报进展，并在遇到问题时及时寻求帮助。实习期也是成长的过程，团队会给予指导，但我们也期待你展现自己的潜力和责任感。

**Q: 如果我觉得自己工作压力很大，怎么办？**
A: 如果感到压力过大，请及时与负责人沟通。团队重视成员的心理健康，可以通过调整任务分配、优化工作流程等方式减轻你的负担。

## 激励与评价

**Q: 分数会对我的岗位或收入产生直接影响吗？**
A: 分数制度主要是为了帮助团队成员了解自己的表现以及改进方向，不会直接与岗位或收入挂钩。但长期的分数表现可能会影响团队对你的综合评价，比如分配任务的复杂度或选择培养的方向。

**Q: 分数归零两次后会发生什么？**
A: 如果分数归零两次后仍然表现不佳，团队可能会与成员进行深入沟通，分析具体原因，并视情况调整任务分配或提出改进建议。必要时，可能会考虑其他安排。

**Q: 加分的标准是什么？**
A: 加分主要基于以下表现：主动帮助他人解决问题、提出创新的技术或流程优化方案、按时高质量完成任务、积极参与团队协作等。具体的加分情况由负责人评估。

## 新人相关

**Q: 我加入团队后多久能完全上手？**
A: 这取决于你的经验和适应能力。通常来说，团队会在一个月内帮助新人熟悉流程和技术栈。如果有任何需要帮助的地方，随时提出来，团队会支持你快速融入。

**Q: 如果我觉得指南中有不合理的地方，应该怎么办？**
A: 你可以随时向团队负责人提出修改建议。指南是在实践中不断完善的，任何合理的建议都会被充分讨论和采纳。
